# 全站一起挖穿地球（共享存档实验）

- **项目目录**：`dig-through-earth`
- **目标定位**：Bilibili Toy 冲官方扶持 / 差异化首选（全站共享存档异步共创实验）
- **核心形态**：纯前端静态网页（HTML / CSS / JS + Canvas + Web Audio），移动竖屏优先，兼容 PC 端

## 核心玩法循环

1. **全站合力掘进**：所有 B 站玩家共同挖掘同一座地球，每次进入可挥铲推进挖掘深度并实时看到当前全站总深度。
2. **多地层奇观与文物图鉴**：每突破指定深度（如地下室 → 地铁 → 恐龙化石层 → 古代秘境 → 地心奇观 → 穿出地球另一端）全站解锁新视觉场景，挖掘过程中随机挖出奇葩地下文物并录入个人图鉴。
3. **深度留名与社交传播**：玩家可在突破深度刻下短留言/里程碑卡片，生成**《地心勘探证书》**海报图分享，天然契合 BIP（Build in Bilibili）连载更新视频。
4. **榜单与身份钩子**：接入贡献挖掘深度周榜，结合关注/投币解锁限定整活铲子皮肤或特效（不卡主流程）。

## Bilibili Toy 技术规范备忘

- **资源与包体**：优先使用 Canvas / SVG 程序化地层绘制与 Web Audio 挖掘/爆文物音效，全部使用相对路径，避免体积超标与白屏。
- **SDK 频控红线（错误码 `307044`）**：
  - **共享存档 & 个人云存档绝不当内存用**：所有点击挖掘全部先在前端内存累加，仅在单轮结算、主动保存或 `visibilitychange` 切后台时通过单次批量接口落盘，严禁每次点击写云端。
  - 严禁使用 `setInterval` 轮询共享存档或排行榜，刷新统一采用本地缓存 + 手动刷新按钮。
