# 绝对证明你是人类（2026地狱验证）

- **项目目录**：`prove-you-are-human`
- **目标定位**：Bilibili Toy 冲爆款播放量首选（反人类递增整活闯关）
- **核心形态**：纯前端静态网页（HTML / CSS / JS + Canvas + Web Audio），移动竖屏优先，兼容 PC 端

## 核心玩法循环

1. **零门槛开局**：以经典的「我不是机器人」勾选框切入，3 秒即可上手。
2. **20–25 关递增地狱验证**：融合 2026 热梗、物理逃逸交互、极速反应、听觉/视觉整活与反转脑筋急转弯，关卡节奏层层加压。
3. **破防与晒分闭环**：记录通关耗时与各关“红温阵亡次数”，通关或翻车后通过 Canvas 生成竖版**《人类纯度鉴定书》**海报卡，方便发评论区与动态晒图。
4. **冲榜与连载**：接入 Bilibili Toy 周榜（按通关耗时排名），后续可根据评论区高赞整活建议持续迭代新关卡。

## Bilibili Toy 技术规范备忘

- **资源与包体**：优先使用 DOM / Canvas / SVG 程序化绘制与 Web Audio 合成音效，全部使用相对路径，避免体积超标与白屏。
- **SDK 频控红线（错误码 `307044`）**：
  - 本地维护游戏状态，仅在关键节点/结算时批量同步云存档（`setCloudStorage`）。
  - `submitScore` 仅在刷新个人最佳成绩时幂等提交一次。
  - `getRankList` 拉取后本地缓存，禁止 `setInterval` 定时轮询。
