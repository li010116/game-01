# 《绝对证明你是人类（2026地狱验证）》工程级详细设计文档（Detailed Design）

## 一、UI / UX 布局规范与视觉设计系统

### 1. 移动端竖屏优先布局（适配 B 站 App WebView）
- **视口容器**：使用 `100dvh` 替代 `100vh`，支持 `env(safe-area-inset-top)` 与 `env(safe-area-inset-bottom)`。
- **核心卡片尺寸**：
  - 宽度：`width: min(calc(100vw - 24px), 420px)`，水平居中。
  - 舞台区（Stage）高度：`min-height: 360px; max-height: 520px`。
  - 触控防误触：舞台容器统一设 `touch-action: none; user-select: none; -webkit-user-select: none; -webkit-touch-callout: none;`。
  - 常规按钮热区 **≥ 44×44 px**；逃跑元素保持 ≥ 48px 隐形点击热区。

### 2. 屏幕结构线框

### 3. 视觉 Token（CSS Custom Properties）

## 二、全 20 关工程级逐关参数与交互细则

### 第一章：好像哪里不对劲（Lv.1–5）
1. **Lv.1 基础人机验证**：`catchCount` 需达 3 次。第 1 次点击旋转 250ms 后长出 SVG 小腿逃向远端；第 2 次随机逃逸（距点击点 ≥ 140px）；第 3 次躲在标题后探头冒汗（48px 热区），点中打绿勾。
2. **Lv.2 强者喝大水**：3×3 九宫格含 3 张真大水 + 1 张叛变格（选中 2 格后或点击后 400ms 翻面变冰美式）+ 1 张「84消毒液」伪装桶 + 4 张饮料干扰项。严格匹配 3 张真大水通过；选 84 触发 `+8%` 硅基专属吐槽。
3. **Lv.3 不听话的滑块**：Canvas 渲染，归一化轨道 `0~1`。当 `|pieceX - holeX| < 0.22` 且 `pieceX < holeX` 时缺口向右加速逃逸，撞右墙 `0.90` 反弹；松手 `|pieceX - holeX| <= 0.055` 磁吸过关（支持逼墙角与反向快甩双解）。
4. **Lv.4 阅读用户协议**：监听 `scroll` 滚动超 `80%` 动态追加废话段落（进度 `98%→99%→99.99%` 永不到底）；真正机关藏在第 3 行红字下划线【绝不烧心】，点击直接通关。
5. **Lv.5 盲停 5.00 秒**：`performance.now()` 计时，`2.50s` 时弹出像素贴纸遮罩计时屏。`|t - 5.00| <= 0.02` 触发 `flags.godTiming = true` 彩蛋（首次判脚本要求重来，二次精准直接膜拜放行）；`<= 0.35s` 通过。

### 第二章：物理失控与感官整活（Lv.6–10）
6. **Lv.6 拍死这只蚊子**：Canvas 舞台。`FLYING` 状态（1.8–2.6s）高速曲线飞行+立体声嗡嗡音，靠近 75px 触发闪避；`LANDED` 状态（0.95s）停止煽翅且音效静音，此时点击 44px 命中圈即拍扁通关。
7. **Lv.7 紧急手摇充电**：12s 倒计时，初始电量 12%，自然掉电 6%/s。支持手摇画圈（每 60° +2.5%）或疯狂点击（每次 +3.5%）。电量过 78% 时弹出 3 个偷电图标使掉电飙升至 22%/s，拍碎图标后冲满 100% 通关。
8. **Lv.8 绝对别按红按钮**：7.0s 倒计时。时间轴依次触发：`5.2s` 变金色“点立减20秒” → `3.6s` 假弹窗【验证过期请点恢复】精准重叠红按钮 → `1.8s` 贴上逼真 SVG 屏幕头发丝。忍住 7s 通关，误点记录 `flags.pressedRedButton = true`。
9. **Lv.9 治好你的强迫症**：初始 `angle = +18°`，`nailTightness = 0`。钉子未敲紧时调正松手 200ms 后受重力滑歪；需先连点顶部松动钉子 3 次敲紧，再将角度调至 `[-1.8°, +1.8°]` 松手过关。
10. **Lv.10 半程BOSS：我要验牌！**：连续 4 张卡片（6.5s/张）：红桃 A（放行）、梅花 14（验牌）、2026年2月30日身份证（验牌）、GPT-99 落款声明书（验牌）。正确拍【我要验牌！】触发全屏 12px 震动 + 拍桌低频重击 + 巨型红章弹飞卡片。

### 第三章：规则叛变与精神污染（Lv.11–15）
11. **Lv.11 地狱密码（手机特调版）**：内置一键词块胶囊键盘（`0–9` + `[2026]` `[不烧心]` `[喝大水]` `[💧]`），5 条动态解锁：长度≥6 → 含 `2026` → 含 `不烧心` → 所有数字和正好等于 `15`（实时显示当前和）→ 突发火焰 🔥，5s 内点入 💧 熄火通关。
12. **Lv.12 找出真正的关闭 ×**：爆出 7 个可拖拽山寨弹窗。点假 `×` 原地裂变 2 个（上限 14 个）；双解法：点击唯一呼吸微光真 `×`，或把弹窗拖开点击底层绿色【全部清空】键。
13. **Lv.13 大脑过载：反色陷阱**：14s 连对 5 题。第 1–2 题按字色；第 3 题洗牌按钮顺序；第 4 题顶栏爆红突变为按字义；第 5 题变为排除法（既非字义也非字色）。
14. **Lv.14 手画一个圆**：Canvas 采点（≥24 点、总扫角 ≥300°、平均半径 R≥35px），`score = clamp(100 * (1 - (std/R)*2.15), 0, 99.9)`。`82%–95.9%` 通关；`≥96%` 触发 `flags.perfectCircle = true`（首次判 AI 要求画丑点，二次依旧≥96% 膜拜放行）。
15. **Lv.15 系统已崩溃！**：350ms 花屏切换蓝屏，8s 回滚倒计时。点假按钮【返回第1关】会被嘲讽并罚 +4s；双解法：手指将红色回滚进度条往左拖回 `0%`，或点击右上角微亮扳手图标 `🔧`。

### 第四章：碳基终极审判（Lv.16–20）
16. **Lv.16 手拽最后 1%**：进度条卡在 99%，右端可拖拽并带非线性橡胶阻力与松手回弹；每次大力拉满累积疲劳值降低下一次阻力，连续猛拽 3 次扯爆 100.5% 通关。
17. **Lv.17 端平一碗水**：Canvas 托盘物理角加速度模拟 + 微风扰动，左右触控保持 `|theta| < 26°` 坚持 5.0s；第 2.5s 天降抽象电子猫猫踩在较轻一侧，制造极限救碗。
18. **Lv.18 极速电车难题**：6.0s 铁轨分叉（左：500 个 B 站收藏夹 / 右：大杯续命水）。选任意一侧火车均急刹并记录倾向；**隐藏彩蛋：直接按住飞驰火车头 0.4s 徒手按停**，解锁 `flags.stoppedTrain = true`。
19. **Lv.19 人机防线微操**：Canvas 发光 S 形激光通道（宽 58px→36px），蓝球视觉半径 12px / 判定半径 8px；手机触摸施加 `y - 24px` 手指防遮挡偏移；终点最后 40px 按钮微微上下颤抖。
20. **Lv.20 终极反转：谁才是人机？**：暗黑终端逐行打字机自白（支持点击秒显），给出最后一个完全静止不再逃跑的勾选框 `[ ] 我是人类，此刻还挺开心的`，勾选后彩带爆发进入鉴定证书页。

## 三、核心数值与《2026 碳基纯度鉴定证书》

- `effectiveMs = rawMs + skipCount * 30000`
- `humanPurity = Number((100 - clamp(rawSus, 0, 99.9)).toFixed(1))`
- `rankScore = Math.max(1, Math.round(10000000 - effectiveMs))`
- 评级分档：`S+`（0跳过且≤95s且失误≤3） / `S`（0跳过且≤160s） / `A` / `B` / `C` / `ERR`
- 14 种动态称号按彩蛋优先级判定（`徒手按停火车的神` > `碳基速通战神` > `人形高精度外挂` > `人间圆规精` > `手稳得像脚本` > `天网派来的潜伏者` > `红温暴躁老哥` > `红按钮终结者` > ...）。
- Canvas `750 × 1180` 离屏绘制高清竖版检验报告（顶部编号、红章评级、三项核心指标、最高血压关卡点名、电车立场、保安终审寄语、防伪条形码），支持长按/点击保存图片 + 一键复制炫耀文案。

## 四、Web Audio 音效与 SDK 架构规范

- **14 种程序合成音效**：`click`、`dodge`、`pass`、`fail`、`slapTable`、`mosquitoLoop`、`splat`、`crank`、`hammer`、`glitch`、`drawTone`、`meow`、`trainBrake`、`fanfare`；监听 `visibilitychange` 切后台自动暂停循环音。
- **关卡隔离契约**：每关只通过引擎注入的 `ctx` 注册 `raf / timeout / interval / on / audio`，切换关卡时引擎统一销毁，零泄漏。
- **SDK 频控守卫（`js/toy-sdk.js`）**：
  - 探测宿主 `window.toy`，本地无宿主自动降级 `MockToyBridge`（`localStorage` + 模拟周榜）。
  - 单 Key `bcaptcha_2026_v1` 合并读写；仅结算或切后台且冷却 ≥10s 落盘；周榜缓存 60s（手动刷新 10s 冷却）；`submitScore` 仅破纪录幂等提交；优雅拦截 `307044`。
- **开发调试条**：支持 `?debug=1` 或 `CONFIG.DEBUG = true` 开启跳关下拉、模拟证书预览与 `307044` 容错验证。

## 五、QA 验收清单
1. 总包体 < 200KB，零外部 CDN，全相对路径。
2. `375×667` / `390×844` / `1280×800` 三端无溢出、无下拉刷新误触。
3. 所有 20 关在连续失败 3 次后稳定弹出【承认我是人机（+30s）】跳过通道，且音频、定时器切换零残留。
