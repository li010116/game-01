# 《绝对证明你是人类（2026地狱验证）》游戏设计方案（GDD）

## 一、产品定位与核心反差感

* **项目目录**：`prove-you-are-human/`
* **目标平台**：Bilibili Toy（优先适配 **B 站 App 移动竖屏 WebView 单手触控**，无缝兼容 PC 浏览器键鼠）
* **单局时长**：熟练玩家 2–4 分钟；普通玩家 4–7 分钟（极适合碎片时间一次打通并晒图）
* **核心幽默基调（从一本正经到彻底发疯）**：
  * **表面伪装**：极度严肃、冷酷的《全网人机安全验证中心 v2026.11（bCAPTCHA）》，采用经典安全验证的白底灰框、B 站蓝（`#00AEEC`）与安全绿配色，右下角甚至一本正经地写着“隐私 · 条款 · 绝不烧心”。
  * **情绪演变**：随着关卡推进，这个“保安系统”会逐渐暴露阴阳怪气、精神失常、甚至打破第四面墙假装崩溃的真面目；最后在第 20 关完成一次出人意料的温情反转，把玩家从“红温暴躁”拉向“会心一笑 + 主动分享”。

## 二、核心循环、数值与视听“果汁感”设计

### 1. 整体流程
1. **伪装首页**：极简勾选框（3 秒直接开玩，零教程）。
2. **四章节 20 关递增地狱验证**：规则叛变 → 物理失控 → 精神污染 → 碳基终极审判。
3. **结算裂变闭环**：一键生成竖版《2026 碳基纯度鉴定证书》海报卡 → 提交周榜耗时 / 复制炫耀文案发评论区 / 再刷速通。

### 2. 三大情绪驱动指标
1. **毫秒级速通计时器**：顶部常驻，精准到 `0.01s`，直接对接 Bilibili Toy 周榜，激发速通玩家二刷三刷。
2. **硅基浓度（Sus-Meter: 0% → 100%） & 红温吐槽栏**：每次犯错、超时、中陷阱都会导致硅基浓度上涨，并弹出不同风格的“毒舌保安评语”。
3. **防流失但极度羞辱的“人机通道”**：任意关卡连续失败 **3 次** 后，底部悄悄浮现 **`承认我是人机（跳过本关，罚时 +30s）`**，既防卡死流失，又激起好胜心。

### 3. 零体积 Web Audio 视听反馈
全部音效使用 **Web Audio API 实时代码合成**（总包体目标 **< 200KB**，右上角提供静音开关）：点击微动、验证通过和弦、红温蜂鸣、拍桌低频冲击波、立体声变频蚊子声、画圆音高上升、倒计时心跳声，并配合移动端 `navigator.vibrate`。

## 三、20 关《地狱验证》逐关精雕清单

### 第一章：好像哪里不对劲（Lv.1–5）
- **Lv.1 基础人机验证**：点击复选框后勾选框长腿跑路，需追着抓捕点击 3 次（第 3 次藏在标题后探头）。
- **Lv.2 强者喝大水**：3×3 九宫格选出所有 2L 纯净大水，混入奶茶、咖啡、伪装成水的「84消毒液」，且有 1 张图靠近时会偷偷翻面变冰美式。
- **Lv.3 不听话的滑块**：拖动拼图时缺口同向逃跑，需将其逼到最右死角反弹或反向惯性甩进缺口。
- **Lv.4 阅读用户协议**：协议滚不到底（99%→99.99%），真正机关藏在第 3 行正文的红字「绝不烧心」里。
- **Lv.5 盲停 5.00 秒**：2.50 秒后数字被遮挡需心算；±0.30s 通过，停在 ±0.02s 内反而被判“太准像脚本！重来”并解锁隐藏称号。

### 第二章：物理失控与感官整活（Lv.6–10）
- **Lv.6 拍死这只蚊子**：合成真实蚊子声，手指靠近就加速逃窜；每 2 秒停下吸血 0.8 秒（声音突然安静），趁机一掌拍扁。
- **Lv.7 紧急手摇充电**：10 秒内狂摇发电机充到 100%，80% 时冒出 3 个偷电弹窗疯狂掉电，先拍掉再充满。
- **Lv.8 绝对别按红按钮**：7 秒内忍住不碰诱人红按钮，期间遭遇假领奖、假“验证超时请点击继续”换皮、假屏幕头发丝诱惑。
- **Lv.9 治好你的强迫症**：把歪了 18° 的画框调正，一松手因钉子松动立刻滑歪，必须先连点 3 下敲紧钉子再调正。
- **Lv.10 半程BOSS：我要验牌！**：连续审查 4 张牌/证件（6 秒/张），识破梅花 14、2 月 30 日出生证、GPT-99 落款，大力拍桌触发震屏特效【我要验牌！】。

### 第三章：规则叛变与精神污染（Lv.11–15）
- **Lv.11 地狱密码（手机特调版）**：内置一键词块胶囊面板，5 条规则动态叠加：含 `2026` → 含 `不烧心` → 数字和为 `15` → 5 秒内点💧浇灭烧毁密码的🔥。
- **Lv.12 找出真正的关闭 ×**：满屏 8 个山寨弹窗，点假 `×` 会裂变；找到唯一真 `×` 或直接划开所有弹窗点底层【清空】键。
- **Lv.13 大脑过载：反色陷阱**：12 秒连对 5 题，前 3 题按字色，第 4 题瞬间反转为按字义，第 5 题反转为排除法。
- **Lv.14 手画一个圆**：极坐标实时算圆度，82%–95.9% 通过；≥ 96% 被判“太圆了像 AI，请画丑点”（解锁隐藏称号）。
- **Lv.15 系统已崩溃！**：假装花屏蓝屏 5 秒后重置回第 1 关；忽略假【重头再来】按钮，直接把错误进度条往回撕开或点角落重启开关。

### 第四章：碳基终极审判（Lv.16–20）
- **Lv.16 手拽最后 1%**：进度条卡死在 99%，手指直接按住进度条右端顶着橡皮筋阻尼猛拽 3 次扯爆 100%。
- **Lv.17 端平一碗水**：平衡水碗 5 秒，第 3 秒天降抽象“电子猫猫”踩在托盘边缘引发极限救碗。
- **Lv.18 极速电车难题**：6 秒在「3年收藏夹」与「快乐水」之间抉择（隐藏神操作：徒手按住火车头强行按停！）。
- **Lv.19 人机防线微操**：按住小蓝点穿过越来越窄的 S 形激光通道，终点按钮在最后 1 厘米微微发抖。
- **Lv.20 终极反转：谁才是人机？**：系统坦白自己才是被困在网页里想观察人类喜怒哀乐的 AI，给出最后一个不再逃跑的真诚勾选框。

## 四、病毒海报：《2026 碳基纯度鉴定证书》

前端 `<canvas>` 离线渲染 `750 × 1180` 竖版鉴定证书，包含：
- 仿官方红章鉴定等级（`S+` / `S` / `A` / `B` / `C`）
- 动态行为称号（`碳基速通战神`、`手稳得像外挂`、`人间圆规精`、`徒手按停火车的神`、`红按钮终结者` 等）
- 最高血压红温关卡点名 + 通关耗时 + 唯一证书编号
- 一键保存图片 + 一键复制炫耀文案发评论区

```text
│       └── ch4.js          # Lv.16–20
├── DESIGN.md
└── README.md
```

### SDK 频控与触控要点
- 云存档单 Key 合并，仅在通关结算或 `visibilitychange`（间隔 ≥ 10s）批量落盘，严防 `307044`。
- 排行榜拉取后本地缓存 60s，绝不 `setInterval` 轮询；`submitScore` 仅破纪录时幂等提交（降序映射 `score = Math.max(1, 10000000 - totalMs)`）。
- 全部拖拽/绘图关卡采用 `Pointer Events` + `touch-action: none`，杜绝手机端误触下拉刷新。

## 六、配套 45 秒发布视频脚本蓝图

1. **0–3s**：点“我不是机器人”结果勾选框长腿跑路，一句话抛出钩子。
2. **3–20s**：逃跑滑块 → 拍桌“我要验牌！” → 画 97% 圆被判 AI → 第 15 关假蓝屏高能快剪。
3. **20–35s**：实机翻车红温瞬间 + 晒出鉴定证书。
4. **35–45s**：指引点视频下方 Toy 零下载试玩，号召评论区晒证书与征集第 21 关脑洞。
