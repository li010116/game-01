## 一、核心美术策略：用“以假乱真”制造 3 秒视觉反差

Bilibili Toy 爆款的核心审美逻辑不是“堆砌 3D 渲染”，而是**「极高辨识度 + 3 秒一眼懂 + 极致反差戏剧感 + 强截屏晒图欲」**。

针对本作的 20 关递增结构，我们提出 **3 套差异化视觉候选方案**，并重点推荐 **「方案 A 为骨架 + 方案 C 关键节点破格爆发」** 的复合美学：

| 方案 | 风格命名 | 核心视觉特征 | 短视频前 3 秒优势 | 推荐指数 |
| :---: | :--- | :--- | :--- | :---: |
| **方案 A（主推）** | **严肃政务安全风 × 渐进崩坏**（Neo-Civic CAPTCHA） | 洁白验证卡片 + 冷静灰边框 + B站蓝 `#00AEEC` + 权威盾牌 + 宋体/等宽编号；随关卡推进逐步被贴纸、红章、蓝屏与故障撕裂 | **最致命的“真假难辨”骗局感**：观众以为 UP 主真被验证码卡住，下一秒勾选框长腿跑路，笑果核爆 | ★★★★★ |

## 二、四幕视觉演进体系（Visual Decay & Emotional Arc）

让美术风格本身参与叙事，随玩家推进呈现清晰的 **4 幕氛围递进**：

1. **第一幕（Lv.1–Lv.5）· 冷静伪装期（Clinical Clean）**
   - 背景 `#EEF1F6` + 极简浅网格底纹（4% 透明度），纯白圆角卡片（`12px`），柔和投影，规范的蓝色主按钮与绿色安全盾牌。
   - **唯一破绽**：细看页脚会发现“隐私 · 条款 · 绝不烧心”，以及勾选框突然长出粗黑 2.5px 简笔画小腿。
2. **第二幕（Lv.6–Lv.10）· 物理入侵期（Tactile Disruption）**
   - 卡片边框偶尔因红温泛起红色脉冲；出现真实感纹理细节（卧室微纹白墙、实木画框+金属翘钉、丝绒深绿赌桌聚光灯、高光立体红按钮与发丝）。
   - Lv.10 拍下【我要验牌！】时，首次解锁 **粗黑描边 + 倾斜 `-12°` 爆红印章砸屏** 的漫画高潮演出。
3. **第三幕（Lv.11–Lv.15）· 失控污染期（Pop Chaos & Glitch）**
   - 色彩饱和度拉高：高能胶囊密码键盘、花花绿绿的粗描边垃圾弹窗满屏飞舞、Stroop 强对比色块闪烁、极坐标发光画圆轨迹。
   - Lv.15 瞬间切换全卡 **RGB 色差故障 + 经典深蓝蓝屏 `#0A2472`**，视觉跌宕达到顶峰。
4. **第四幕（Lv.16–Lv.20）· 撕裂与反转期（Physical Break → Warm Terminal）**
   - Lv.16 进度条被物理拽变形甚至撑出卡片边框；Lv.17 亮蓝物理水波 + B 站粉电子猫猫；Lv.19 赛博暗黑霓虹激光通道。
   - Lv.20 整页温柔淡入 **`#0D1117` 终端暗黑模式** + 柔和薄荷绿终端光点 + 最终纯白静止勾选框 + 彩带烟花。

## 四、字体排版与数字层级规范（零外部字体包，全系统栈极速加载）

为确保整包 < 200KB 且国内 iOS / Android / Windows / macOS 全端秒开一致：
- **UI 正文栈**：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`
- **数字 / 计时器 / 编号 / 终端栈**：`"JetBrains Mono", "SFMono-Regular", ui-monospace, Menlo, Consolas, monospace` + 强制 `font-variant-numeric: tabular-nums`（防止毫秒计时器疯狂左右抖动！）。
- **证书正式标题 / 红章栈（仿公文报告反差感）**：`"Songti SC", "STSong", "Noto Serif SC", "SimSun", Georgia, serif`（用严肃宋体排布离谱称号“人间圆规精”，喜剧效果直接翻倍！）。

### 字号阶梯（移动端 390px 基准）

## 五、图形与插画语言（零位图依赖，纯 SVG + Canvas 统一风格）

为了避免不同关卡像“拼凑的素材大杂烩”，全作所有图形元素（桶装大水、84消毒液、蚊子、手摇把手、歪画框、扑克牌、电子猫猫、像素小火车）统一遵循以下 **3 条画风铁律**：
1. **统一几何扁平 + 2.5px 粗黑描边（`#18191C`）+ 局部双色扁平阴影**：既有手绘表情包的可爱幽默感，又在纯白验证卡片上拥有极强的视觉聚焦度。
2. **“豆豆眼”万物有灵法则**：复选框逃跑时、偷电图标、电子猫猫、火苗、甚至 99% 卡住的进度条小重物，全部点缀一对极简的 `3px` 黑豆眼或 `>_<` 颜文字表情，瞬间注入 B 站二创灵魂！
3. **高清渲染防模糊**：所有 `<canvas>` 严格乘以 `dpr = Math.min(window.devicePixelRatio || 1, 2)`，保证视网膜屏线条锋利如刀。
